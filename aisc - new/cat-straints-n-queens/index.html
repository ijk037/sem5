💡 CSP Formulation: (X, D, C)

Academic Model
👑 Variables (X) X = { Q₀, Q₁, ..., Qₙ₋₁ }

Each variable Qᵣ represents the kitten in row r. Exactly 1 kitten per row is placed, implicitly satisfying the row constraint.

🎯 Domains D(Qᵣ) D = { 0, 1, ..., N - 1 }

Possible column values for each row. Forward checking prunes attacked column coordinates from future rows.

⚔️ Constraints (C)
No Same Column: Q[i] ≠ Q[j]
No Same Diagonal: |Q[i] - Q[j]| ≠ |i - j|
🔄 Solving Mechanism

Forward Checking: Eliminates conflicting moves ahead of time. If any row has 0 legal options left (Domain Wipeout), the search immediately Backtracks to try the next valid choice.

⚔️ Algorithm Showdown: Backtracking vs. Hill Climbing

Compare Systematic Search (Backtracking) with Local Heuristic Search (Min-Conflicts Hill Climbing) on the exact same board size!

🔍

Backtracking (DFS)

Systematic Tree Search
Guaranteed Complete

Systematically builds a solution one row at a time. Each queen assignment is tested against all previously placed queens. If a conflict occurs or forward checking detects a dead end, it backtracks to try alternative columns.

Key Mechanism:
  • State Representation: Partial assignment (0 to N queens placed).
  • Pruning: Abandons entire subtrees as soon as constraints are violated.
  • Completeness: 100% complete (always finds a solution or proves none exists).
  • Time Complexity: O(N!) worst-case factorial, reduced dramatically by pruning.
  • Space Complexity: O(N) recursion stack memory.

⛰️

Hill Climbing (Min-Conflicts)

Local Heuristic Search
Heuristic Optimization

Operates on complete states with all N queens on the board. In each iteration, it selects a conflicted queen at random and moves it to the column within its row that minimizes the objective conflict heuristic h(n).

Key Mechanism:
  • State Representation: Complete state (all N queens placed simultaneously).
  • Heuristic Function: h(n) = number of conflicting queen pairs. Goal is h(n) = 0.
  • Plateau Escape: Random restarts prevent getting trapped in local minima.
  • Empirical Speed: Solves massive boards (N = 10,000+) in almost linear O(N) time!
  • Space Complexity: O(N) constant memory (just the 1D position array).
